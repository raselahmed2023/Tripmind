## JWT Flow

```
Register/Login:
  1. Validate input (Zod)
  2. Find or create user
  3. Compare password (login only, bcrypt.compare)
  4. Generate accessToken (15m) + refreshToken (7d) via jsonwebtoken
  5. Set refreshToken as httpOnly cookie
  6. Return { success, message, data: { user, accessToken } }

Access Protected Route:
  1. Extract "Bearer <token>" from Authorization header
  2. Verify with JWT_SECRET
  3. Attach decoded { userId, email, role } to req.user
  4. Controller handles the request

Refresh Token (future — not implemented yet):
  Cookie-based refresh token flow is scaffolded (cookie is set),
  but no /refresh endpoint is created per requirements.

Logout:
  1. Clear refreshToken cookie
  2. Return success
```
